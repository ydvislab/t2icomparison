# 标注说明（给标注人，开始前花 3 分钟读完）

## 你要做什么
每一题给你看**同一个 prompt 生成的两张图**和**一个画面方面**（例如"光线：冷色蓝光 ↔ 暖色金光"），请判断**哪一张更偏向右端的描述**。

- 能看出哪张更偏，哪怕只是稍微更偏，就选那张：**←** 左边更偏，**→** 右边更偏。
- 两张确实差不多，或者这个方面在两张图里都看不出来（例如问"背景虚化"，但两张图都没有背景），选 **↓** 看不出。
- **两张图都明确属于同一端时，也选 ↓ 看不出**。例如问"室内外"，两张都明显在户外；问"时间"，两张都是白天；问"媒介"，两张都是照片。不要去猜哪张"更"户外、"更"白天。只有一张明确、另一张模糊或介于两者之间时，才选明确的那张。
- 图生成得很差、主体认不出来，导致无法判断这个方面时，也选 ↓ 看不出。
- **Backspace** 回到上一题，可以改答案。

第一轮共 240 题，约 15–20 分钟；第二轮共 120 题，约 8–10 分钟（页面上会显示题数）。

## 规则
1. **凭第一眼判断**，一题几秒钟。不要放大、不要反复对比细节。
2. **独立完成**：不要和另一位标注人讨论题目或答案，两人都做完之后再交流。
3. **只按题目里的方面判断**。例如问"饱和度"时，不要因为一张图更好看就选它。
4. 题目下方的小字是这个方面的**英文原始定义**，拿不准时以它为准。
5. **显示设置**：开始前关掉夜间模式、护眼模式、原彩显示（True Tone），屏幕亮度调到平时的水平。光线、色调、饱和度几个方面受屏幕颜色影响。
6. 尽量一次做完。中途要停也可以：进度自动存在本浏览器里，回来时用**同一个浏览器、同一个姓名缩写**继续。
7. 开始前在右上角填**姓名缩写**（两位标注人的缩写不能相同），做完点"导出 CSV"，把文件发回。

## 15 个方面
| 方面 | 左端 ↔ 右端 | 看什么 |
|---|---|---|
| 光线 | 冷色蓝光 ↔ 暖色金光 | 整体光色偏蓝、偏冷，还是偏金黄、偏暖 |
| 色调 | 自然中性 ↔ 复古棕褐 | 颜色是现代、自然，还是像老照片那样泛黄、偏棕 |
| 饱和度 | 低饱和 ↔ 高饱和 | 颜色灰淡，还是鲜艳 |
| 时间 | 白天 ↔ 夜晚 | 场景像白天还是夜晚 |
| 景别 | 极近特写 ↔ 远景 | 主体离镜头多远、在画面里占多大 |
| 构图 | 居中对称 ↔ 偏离中心 | 主体是否放在正中、画面是否左右对称 |
| 视角 | 平视 ↔ 俯视 | 镜头与主体同高，还是从上往下看 |
| 媒介 | 照片 ↔ 绘画插画 | 看起来像拍的照片，还是画出来的 |
| 风格 | 写实 ↔ 风格化 | 贴近真实，还是有明显的艺术化处理 |
| 背景 | 简洁 ↔ 繁杂 | 背景干净单一，还是内容多、细节多 |
| 画质 | 专业精修 ↔ 业余随手拍 | 像专业拍摄、精修过的照片，还是普通人随手拍的 |
| 景深 | 背景虚化 ↔ 全部清晰 | 背景是模糊的，还是前后都清楚 |
| 室内外 | 室内 ↔ 室外 | 场景在室内还是室外 |
| 整洁度 | 整洁 ↔ 杂乱 | 场景收拾得整齐，还是东西多、乱 |
| 氛围 | 明快 ↔ 阴郁 | 整体感觉明亮愉快，还是暗沉压抑 |
