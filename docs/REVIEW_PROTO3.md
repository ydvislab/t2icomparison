## 结论
**继续做原型 3，但不要把"等高线画得好看"当成研究进展。** 先修好"看得到证据"和"读数不出错"，再用实验检验这种比较方式是否真的帮人做出更好的判断。
- 评分：**问题意义 7/10，可视化贡献 3/10，成熟度 2/10**（与原型 4 评审时基本相同）。
- rev4 确实比 rev3.1 清爽，但"清爽"本身不能证明比较得更好。
- 按现有证据作为 VIS/TVCG 投稿会被拒：13 组只是 4 个模型的几种设置，还没有真正的"多模型"场景；没有完成的任务研究、对比实验或方面的人工验证。ViBEx 已经有 CLIP 图像条带和看图核验，并把跨模型比较列为未来工作，"加几列模型 + 一张等高线图"增量太小。

## 一、遗留错误（逐项核对代码后）
| 问题 | rev4 现状 | 最小修法 |
|---|---|---|
| SD1.5 嵌套样本 | 只在咖啡上存在（768 条记录中 760 张不同的图）；README 说"每个 prompt"是错的 | 写清楚是哪个 prompt；重复的图不能当独立证据，也不能在汇总基线里重复计权 |
| "蒸馏"对照 | 实际同时换了模型权重、步数 28→4、CFG 4→1；rev4 界面本身没写"蒸馏" | 在界面上写清每组的模型、步数、CFG、分辨率和实际 prompt；结论只针对这些配置组合 |
| 相对分数被说成绝对类别 | **基本已改好**（"相对偏……"、选中 vs 其余） | 再写清"相对于哪一群图" |
| 带符号平均掩盖相反变化 | 当前没有跨方面的带符号汇总；选中面板逐方面报差值，是对的 | 保持逐方面；不同 prompt 之间的相互抵消仍存在（见下） |
| "全部 prompt"混合含义 | **仍存在**：矩阵用合并后的中位数/四分位距，悬停的离散度却是各 prompt 的平均 | 改为按 prompt 显示效果和反转，或暂时去掉"全部" |
| 没有不确定性 | **部分解决**：离散度有 90% 自助法区间，但中位数、等高线边界、跨 prompt 推广都没有 | 写清区间针对什么；支撑结论的比较补不确定性，并补独立样本 |

评审另外发现的三点：
- **重复检测靠的是"方面分数四舍五入后相同"，不是像素。** 这次恰好全对，但在别的 prompt 下也会显示这个全数据集的警告。
- **"同一个 prompt"有时只是"同一个主题"。** caption 式、任何风格的组实际用的生成文字不同；klein 是 768²，klein·极简是 512² 且种子不同。build.py 导出时丢掉了实际 prompt 和生成设置。
- **隐藏某些组会悄悄改变统计基线。** 例如"城市街道 / Turbo / 色调"，中位数不变（1.567），但离散度在全部可见时是 0.782，只看三个模型时是 0.348，只看 Turbo 时是 1.000。要固定一个分析范围，并区分"改变比较范围"和"只是不画出来"。
- **跨 prompt 的反转是真实存在的：** Turbo 的构图中位数在"房子"上是 +1.311，"厨房"上是 −1.326，合并六个 prompt 后变成 +0.074，反转被藏起来了。

## 二、目标与任务抽象
建议把目标改成：
> 帮助模型开发者和评测者，在**明确的生成条件**下比较并**看图核实**各组输出的主要外观、各方面的变化范围，以及反复出现的组合。

- "集中在哪里"应指**集中在哪些外观或方面取值上**，而不是投影图上的哪个岛。
- "集中"只描述这批样本；8 或 16 张图不能说明模型"固定了"某个属性或"失去了"某种能力。
- 支持的决策：选哪些模型或设置进入候选、哪个疑似退步值得深究、下一步该做什么实验。
- 六个具体任务：
  1. 确定可比较的组、设置、样本量和参照组；
  2. 找出在**位置**、**范围**或两者上都不同的方面；
  3. 在同一方面区间里比较不同模型的典型图和例外图；
  4. 研究反复出现的组合（如某种色调总是配某种构图）；
  5. 看图检查自动排序和描述是否站得住；
  6. 检查不同 prompt 之间是否一致，并记录带证据和反例的结论。
- 这些还只是**提出的任务**，不是用户需求；形成性研究文档只是计划，招募四类人也比现在的定位宽。

## 三、PrompTHis 可借鉴之处（借思路，不借图的结构和外观）
PrompTHis 的边编码的是"prompt 改了什么"，与"比较互相独立的模型样本"是两个问题。值得借的是**把图像证据和有意义的关系连起来**：
1. **恢复"少量缩略图 + 其余是点"。** rev4 的总览只看到彩色的岛，看不到岛里画的是什么。挑少量清晰的缩略图（含一张典型、一张例外），其余保留为点；悬停区域时再展开更多。注意：几张同样大的代表图不能暗示它们一样常见，要保留全部点或标出数量。
2. **借它的防重叠手法，但保留真实位置。** 缩略图挪开时保留原位置的锚点和短连线；选择和包络都用原始位置算。条带里也要保留真实分数位置，或者明确说明按格子选。
3. **"画面模式的圈"和"模型的轮廓"要分开。** 画面模式的圈应**跨模型**收集同一种外观；模型轮廓只用来追踪某个模型的样本。多模型比较真正要问的是"这种外观在每个模型里有多常见"，而不是"每个模型的圈有多大"。最多画几个重点模型的轮廓，不要叠 20–50 个彩色包络。
4. **把 rev3.1 的占比信息找回来，但不要卡片。** 选中一个区域时，给**每个模型**一条对齐的 k/N 条（包括 0），这能抵消 8 张与 16 张的样本量差异。rev4 的选中面板已经按模型内比例算了，是对的；下一步是在查看区域时就显示，并把占比为 0 的模型也列出来。
5. **只在按需时给一句对比式说明。** 例如"这个区域有 A 的 k/N、B 的 j/M；它的 CLIP 复古分数比其余可见图高"，旁边并排放选中图和对照图。基于方面的描述只能当作待核实的假设。
6. **差异编码要服务于"与参照组比较"。** 词语变化字形、有向边在独立的模型样本之间没有自然含义。用对齐的分布、明确的参照组，位置和范围分开表示；画面模式用"占比差"。现有的中位数/四分位格子和参照灰条是合适的基础，新造一个放射状字形不太可能更好。
7. **借"一个主导的分析焦点"，不一定是主导的投影图。** 主视图应是**以图像为依据的、对齐的方面分布比较**；投影图用来发现和框选意外的外观。rev4 把大块空间给了未经校准的投影图和一开始是空的面板，却把图像证据挤进很细的行里，主次颠倒了。
8. **恢复内嵌的图例和必要的上下文。** 中位数/四分位的含义、相对分数的基线、样本量、参照组、选择范围要一直可见；只有具体读数放进悬停。图例是读图所必需的，不是可以删掉的文字。

**不建议优先做：** 布局参数滑块、带宽滑块、小地图、继续调深色侧栏样式。

## 四、设计批评
- **三条原则用得太死。** "用编码代替文字"减少了杂乱，但也去掉了可见的含义；"按需展开"适合单张图和精确读数，不适合分母和图例；"视图之间不重复"尤其有害：协同视图需要重复的组颜色、参照组和选择提示才能连贯。
- **等高线图不能做主要的定量视图：**
  1. 现在的阈值取的是"该组各点处密度"的分位数，最多算"大约覆盖多少样本的包络"，不是 50%/90% 的概率区域，也不是不确定性区间；8 个点时边界的平滑程度远超样本能支持的精度。
  2. 更严重的是说明里写了"包络越小越集中、重叠说明结果相近"。t-SNE 不保留支持这种读法的几何关系（参见 distill.pub《How to Use t-SNE Effectively》）；横纵分别归一化、按屏幕缩放也会改变形状；换成 UMAP 也不能解决。
  - 建议：保留投影图作为"探索用的图像索引"，删掉关于面积和重叠的说法，"集中程度"只在看图核实过的方面分布里比较。
- **现有的实现缺陷（执行方已复核第 1 条）：**
  1. 条带里同一格的图完全叠在一起，只有最上面一张能看到、能悬停（行高 14–30 像素时堆叠间距为 0）。
  2. 有的图看得见却刷不到：例如"城市街道 / 色调"的显示范围从 −2.240 开始，但有一张图分数是 −2.396，显示时被压进第一格，刷选时却按真实分数判断而漏掉。显示位置和刷选判断不一致。
  3. 选择联动不完整：投影图的框选不会反映到矩阵；勾选"只看重点"后，共用轴的选择带仍画在矩阵的所有列上；参照组只影响矩阵灰条，而选中面板的"相对偏向"用的是其余可见图。
  4. 保存的发现缺少比较上下文：选 klein → 保存 → 隐藏 klein → 恢复，顶栏显示已选 16 张而面板显示 0 张；保存时没有记录隐藏的组和参照组。
- **扩展到 20–50 组：** 不要继续把所有东西压进一屏。用可滚动的总览（比如模型为行、方面为列），固定排序、家族可展开、参照组固定，给选中的组可读的细节行。不要悄悄把同一家族的设置合并成一个分布。
- **评审认可、应保留的：** 每个 prompt 内共用坐标、不把不同 prompt 的图拼在一起、方面的共用轴、中位数与四分位分开、参照灰条、按模型内比例算选中占比、重点颜色最多 3 个。

## 五、改进计划（评审给出的优先顺序）
1. **让比较对象一目了然。** 把实际 prompt 和生成设置带进数据；更正咖啡上的重复说明；区分"换模型"和"换一整套设置"。成功标准：评测者能准确说出两组差在哪里，重复的咖啡样本不被当作独立复现。
2. **修正统计读法。** 固定并写明分析基线；删掉投影图面积/重叠的说法，说明包络的含义；把"全部 prompt"的合并汇总换成按 prompt 的效果，或暂时去掉。成功标准：隐藏标记不会悄悄改变数值；房子/厨房的反转能看到。
3. **每张图都能看到、刷选前后一致。** 条带给可读的最小行高（可滚动或可展开的堆叠）；用完整的分数范围；显示位置和选中判断一致。成功标准：所有样本都能检查，整条轴刷选能选中所有显示的图。
4. **选择和发现的状态要连贯。** 显示选择范围和比较基线；矩阵里反映选中数量；列出选中数为 0 的组；保存和恢复时带上组的可见性和参照组。成功标准：各视图里的图和数量一致，包括"保存—隐藏—恢复"之后。
5. **围绕一个清楚的比较重建主次。** 所有组的总览做得紧凑；放大当前方面的图像分布；恢复一个小的常驻图例；投影图加少量带锚点的缩略图。成功标准：不用逐点悬停就能看出重点组的主要外观和例外；要直接和 rev4 对比，不能只看外观。
6. **验证方面，说明改成对比式。** 人工核对一小批典型、极端和有分歧的图；给复合的或说过头的方面改名（"画质"测的是"专业摆拍 vs 随手拍"的文字，不是生成质量；"色调"混了新旧与配色，"构图"混了居中与对称）；选中图和对照图并排放。成功标准：用户能否定没有依据的自动描述；报告的方面结论经得起看图。
7. **增加有针对性的比较深度和规模。** 按 prompt 的一致性检查；一个共用的双方面联合查看，用于研究反复出现的组合；家族展开加固定参照组。在需求被证实之前不要再加新的自动聚类模块。成功标准：能发现反转，能区分"单个方面分布相同但组合不同"，能完成真实的 20–50 组比较且图不至于小到看不清。
8. **做一个能证伪贡献的评估。** 现在就开始任务访谈，与开发并行；之后在相同的图和分数下，与"图像网格 + 指标表"和"对齐的属性分布 + 联动图像"两种强基线比较；任务要包含位置偏移、集中程度变化、多峰、CLIP 排序误导、新增的独立样本。成功标准：判断正确率、证据质量或用时更好（不只是更喜欢），并有一个专家做出重要分析决定的案例。
