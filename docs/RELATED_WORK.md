# 相关工作与定位

> 论文相关工作一节（约 800 词）的素材。受 CG&A 20 篇参考文献的限制，正文只引 `OUTLINE.md` 中列出的 20 篇；这里多列的工作用于自己把握定位，必要时放进侧栏（侧栏引用不计入 20 篇）。

## 1. 三类相关工作
| 类别 | 工作 | 做了什么 | 和本文的区别 |
|---|---|---|---|
| 多样性与默认值的度量 | Vendi（2210.02410）、DIMCIM（2506.05108）、DefaultShift（2608.21784） | 多样性指标；默认多样性随模型进步下降；属性级的默认值漂移（封闭词表） | 给出数字或属性表，不提供"看图核实"的比较表示 |
| 引导与蒸馏降低多样性 | CFG（2207.12598）、CADS（2310.17347）、Distilling Diversity and Control（2503.10637）、ADD / SDXL-Turbo（2311.17042） | 机制与缓解方法 | 本文只借其解释案例中的现象 |
| 生成图像的可视分析 | CUPID（2406.07699）、ViBEx（2504.19703）、Varif.ai（2506.19644）、POET（2504.13392）、PrompTHis（2403.09615）、Concept Lens（10.1109/TVCG.2025.3564537） | 单个模型或单个查询的输出分布；概念条带与图像证据；属性直方图联动图片；自动找出同质维度并扩写 prompt；prompt 编辑历史 | 都不是把**多个模型或设置放在同一套坐标上**比较，也不处理"比较是否成立" |
| 可视比较 | Gleicher et al. 2011（10.1177/1473871611416549）、Gleicher 2018（10.1109/TVCG.2017.2744199） | 并置 / 叠加 / 显式编码的分类与考量 | 本文的设计依据：组多时总览用叠加和显式编码，并置只留给挑出的少数几组 |
| 默认外观现象 | Default Images in T2I（CHI 2026，2505.09166）、Visual Fingerprints（2605.06054） | Midjourney 的"默认图"；LLM 多次输出的"指纹"跨条件比较 | 前者是人工亲和图分析；后者是文本版的思路 |

## 2. 最接近的工作：ViBEx（EuroVis 2025）
- 已经用**真实生成图的缩略图作为标记**，沿图文相似度轴排成条带（包括"画作风格"这类非物体概念），并支持看图核对。
- 比较的是选定的概念查询；**跨模型比较是它写明的未来工作**。
- 外部评审的判断：只把 ViBEx 的"锚点组"换成"模型组"，增量太薄。

## 3. 其他需要正视的工作
- **Varif.ai**（DIS 2025）：用户或 LLM 定义属性，按属性画直方图并联动图片，本身就支持核验多样性。
- **POET**（UIST 2025）：已能自动找出一批生成图里哪些维度是同质的。"找出什么被固定"不是新操作。
- **Weinmann et al.**（New Media & Society 2026，10.1177/14614448261435197）：已用平均人脸比较不同平台的生成结果。平均图不能作为新意。
- 更早的：AverageExplorer（平均图交互）、VAICo（按层级组织图像差异）、Ravel（跨生成器比较）。"第一个视觉摘要""第一个跨生成器的可视比较"都不能声称。

## 4. 本文可以主张的增量
只能落在下面这个**组合**上，并用案例和专家反馈支撑：
1. **多组对齐比较**：所有组共用每个方面的坐标轴和每个 prompt 的投影；一次刷选同时选中所有组的同一区间。
2. **三种差别分开**：位置（集中在哪里）、范围（有多集中）、外观占比（某种外观在各组里各占几成，含 0）。两组可以同样集中、但集中在不同取值上；也可以位置偏移了、却没有变得更单一。
3. **比较成立的条件**：写清每组的生成设置；改动超过一项时不归因于其中某一项；重复使用的样本只算一次；隐藏组不改变统计基线；按 prompt 分开，不让反转被平均掉。
4. **每个读数都能回到图像核实**，方面本身经过人工核对。
