# PacificVis 2027 paper: LaTeX sources

The paper is built on the official IEEE VGTC conference template, release 2024.02.14 (`template.tex` structure, `vgtc.cls`, `abbrv-doi*.bst`; the release linked from the VGTC conference page). Draft 5 (2026-10-27): preliminary study in the text-to-image domain, design requirements, DefaultScope, two case studies, expert study. Chinese reading copy: `../paper_pvis_zh.md`.

## Files
- `main.tex`: the paper.
- `refs.bib`: generated by `make_bib.py` from DataCite (arXiv DOIs) and Crossref; do not edit by hand.
- `make_overleaf.sh`: assembles `../pvis_overleaf.zip` (sources and figures) and test-compiles it on the server with pdfLaTeX + BibTeX (TinyTeX, TeX Live 2026; the same toolchain as Overleaf), writing `../pvis_overleaf_test.pdf`. The template's own example uses `tabu`, which no longer compiles with current TeX Live; the paper does not use it.
- Figures: generated into `../figures/` by `../shots.mjs`, `../make_figures.py` and `../make_data_figures.py`. They are not in git.

## Overleaf
1. New Project → Upload Project → `pvis_overleaf.zip`.
2. Compiler: pdfLaTeX (Menu → Settings).
3. Review mode is double-blind (`\documentclass[review]{vgtc}`):
   - after abstract registration in PCS, set `\onlineid{...}`;
   - for single-blind review, switch to `\documentclass{vgtc}` and fill in `\author`.
4. Red `[...]` marks open items:
   - authors;
   - one citation in Sec. 2;
   - case 6.5;
   - the expert study;
   - the supplemental link;
   - the AI-use disclosure to confirm;
   - acknowledgments.
