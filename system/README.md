# 可视比较系统（rev4.1）

## 运行
需要先有 `aspects/build.py` 的输出（`$T2IC_DATA/proto2/`）和两组生成图像。

```bash
python3 build.py
```

```bash
cd ~/va4ext/proto3 && python3 -m http.server 8771 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8771/index.html 。`build.py` 需要 scikit-learn、pandas、PIL；所有数值都在构建时算好，浏览器端只读 `data.js`，不需要 GPU。

## 构建做了什么
- 从 `aspects/` 的输出读取 CLIP 特征和 15 个方面分数，从两个背景实验的 `meta.csv` 和 `config.py` 读出每组的权重、步数、CFG、分辨率、prompt 写法和每张图实际用的生成文字。
- 逐像素查找被两组重复使用的图（`dupOf`）：只有 "a cup of coffee" 上 SD1.5 CFG7.5·极简 的 8 张与 SD1.5 组相同。
- 每个 prompt 内，对全部 13 组的图做一次联合 t-SNE（perplexity 15，余弦距离，random_state 0），所以所有组共用同一套坐标。
- 输出 `data.js`（META：prompt、方面、组及其设置；IMGS：每张图的组、prompt、生成文字、种子、方面分数、投影坐标）。

## 界面
一屏仪表盘（最小 1180×700，在 1440×900 和 1920×1080 下测试过）。左侧栏选 prompt、组的显示与重点（最多 3 个重点组：蓝、橙、青）。

| 视图 | 比较方式 | 内容 |
|---|---|---|
| 图像空间 | 叠加 | 本 prompt 全部组共用的投影；每张图一个点；重点组用"样本覆盖"线（≈50% / ≈90%）标出样本所在处，**只用于追踪，不读集中程度**；可框选；可按当前方面着色 |
| 方面 × 组矩阵 | 显式编码 | 行 = 15 个方面，列 = 组；每格是该行共用横轴上的迷你箱线：竖线 = 中位数，色条 = 中间 50%；可设参照组（灰色底条）；列头显示"选中数 / 样本数"，格内紫色短线标出选中的图 |
| 方面分布条带 | 按需并置 | 当前方面上每组的全部图像，中心放在真实分数处，挤不下时向上错开；顶部共用轴拖动 = 在所有显示的组上选中同一区间；行内拖动只选这一组 |
| 选中面板 | 反向解释 | 选择来源和对照组；每组被选中的比例（含 0）；选中图与其余图相比在哪些方面相对偏向（本 prompt 内标准差为单位）；按组分开的图像 |

**共享状态**：重点组、当前方面、选中的图、悬停的组、参照组。任何视图中的操作都会更新这些状态。
**设置溯源**：悬停组名显示设置；选了参照组时列出相差的每一项，改动超过一项时注明"不能归因于其中某一项"；悬停图像显示实际生成文字。
**记录**：保存备注和当时的视图（显示的组、参照组、选择带），可恢复、可导出 JSON（存在浏览器 localStorage `p3_findings`）。

## 统计口径
- 方面分数在每个 prompt 内相对全部组标准化；方向一律写成"相对偏向"，不写成类别。
- 分析范围固定为本 prompt 下全部 13 组的图，重复使用的图只算一次；隐藏组只是不画出来，数值不变。
- 集中程度 = 组的四分位距 ÷ 本 prompt 全部图的四分位距；中位数和集中程度都有 90% 自助法区间（300 次重采样，分母固定）。
- 不提供"全部 prompt"合并视图（会掩盖 prompt 之间的反转）。

## 已知局限
- 方面是 CLIP 代理测量，尚未经人工核对（见 `annotation/`）。
- 每组 8 或 16 张，只能描述这批样本。
- 投影是 t-SNE，只保留局部邻近关系。
- 组数增多到 20–50 时的布局尚未设计。
