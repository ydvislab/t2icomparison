多模型输出比较

PROMPT

模型与设置

图像空间

?每个点是一张图。位置来自 CLIP 特征的 t-SNE 投影，本 prompt 下所有组共用坐标。投影只保留"哪些图彼此相近"的局部关系：圈的大小、形状和重叠不能读成集中程度或相似程度，比较集中程度请看矩阵和方面分布。彩色线圈出重点组的样本所在处（粗线约覆盖该组一半的点，细线约九成），只用来追踪这个组的图落在哪里。悬停点看图，拖动框选，悬停侧栏或矩阵列头中的组以虚线显示它的范围。

方面 × 模型

?每行一个方面，每列一个模型或设置，列头下的数字是样本数（有选择时为"选中数/样本数"）。格子内的横轴是该方面的 CLIP 分数（左端描述 → 右端描述，悬停行名可见），同一行共用一条轴。分数在本 prompt 内相对全部组标准化（重复使用的图只算一次），隐藏某些组不会改变数值。竖线 = 中位数，色条 = 中间 50% 的范围（越窄越集中）；灰色底条 = 参照组；紫色短线 = 当前选中的图。悬停格子看数值和 90% 自助法区间。点列头设为重点，点行名设为当前方面。

方面分布

?每行一个模型（顺序同矩阵的列），每张图的中心放在它在当前方面上的真实分数处，挤不下时向上错开，所以每张图都看得到；行太多时可上下滚动。在顶部轴上拖动：所有显示的模型一起选中这一段；在某一行里拖动：只选这一行。框选的依据就是图中心的位置。

选中

?框选后显示：每个可见组被选中了几张（占该组的比例，包括 0）；选中的图与本 prompt 其余全部图相比，在哪些方面相对偏向一端（单位：标准差，CLIP 分数，是相对比较而不是类别判断）；图像本身。
