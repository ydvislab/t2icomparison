多模型输出比较原型 3 · rev3

PROMPT

模型与设置（点名字：设为重点；点方框：显示/隐藏）

⚠ = 与另一组有重复图像（同设置同种子）。
方面分数来自 CLIP，是相对所有组的近似测量，请以图像为准。
A

图像地图

?当前 prompt 下所有显示中的组的图，放在同一张图像空间里（CLIP 特征的 t-SNE，各组联合计算，坐标对所有组相同），相似的图离得近；缩略图已自动错开避免重叠。
彩色气泡 = 重点组的"领地"：气泡越小越集中，重叠说明默认结果相同。
灰色注释框 = 自动找出的画面相近的一团图：写明有多少张、主要来自哪些组，以及与其余图相比偏向哪些方面（相对比较，不是绝对判断）。点注释框即可选中这团图。
拖动框选；悬停看大图；侧栏中悬停某组会高亮它的图。
B

方面 × 组

?每行一个方面（两端各一种描述），每列一个显示中的组。格子里的横轴 = 该行方面的分数（左端 → 右端），同一行共用这条轴。竖线 = 中位数（相对所有组，集中在哪一端），色条 = 中间 50%（越窄越集中）。左上角图例画出了这些含义。
选了"参照组"时，灰色底条是参照组的范围；C 中共同轴刷选后，当前方面那一行画出刷选区间；框选图片后，列头下方紫条 = 选中图占该组的比例。
列按"固定方式"相似度排序，行按组间差异排序。点列头：设为/取消重点组；点行名：设为当前方面。
C

细看

?每行一个组（顺序同 B 的列），横轴是当前方面（共用）。图像按分数放在横轴上并向上堆叠，堆得越高 = 越多图在这里。每行下方：竖线 = 中位数，色条 = 中间 50%。右侧：离散度及其 90% 自助法区间（同一组只有 8 或 16 张图，区间越宽越不可靠）。
顶部共同轴上拖动：所有组同时选中这一区间；某一行里拖动：只选这一组。

选中的图

?框选一批图后：选中与其余的平均图；来自哪些组；与同一 prompt 下其余图相比偏向哪些方面（相对比较，单位为标准差）；按组的图像证据。"记录为发现"保存当前视图和备注。没有选择时显示当前方面上各组的集中程度排名（含区间）。
