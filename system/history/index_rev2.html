生成集合比较 · 原型 3

A

共享图像地图

?所有组的图放在同一张图像空间里（CLIP 特征的 t-SNE，各组联合计算，坐标对所有组相同），相似的图离得近。
方块 = 各组的平均图，放在该组所有图的中心。
彩色区域 = 重点组的"领地"：面积越小越集中，两块领地重叠说明默认结果相同。
拖动可框选一批图；点方块可把该组设为或取消重点组；鼠标停在方块上会用虚线画出该组领地。
B

方面 × 组

?每行是一个"方面"，两端各是一种描述（例如 色调：自然中性 ↔ 复古棕褐）。每列是一个组（一个模型或一种生成设置）。
每个格子里的横轴 = 该行方面的分数，从左端描述到右端描述；同一行的格子共用这条轴，可以直接上下比较位置。
格子里：竖线 = 该组的中位数（集中在哪一端）；色条 = 中间 50% 的图所在的范围（越窄越集中）。
左上角的图例格画出了这些含义。选了"参照组"时，灰色底条是参照组的范围；在 C 的共同轴上刷选后，当前方面那一行会画出刷选区间。
列按各组"固定方式"的相似度排序，行按组间差异从大到小排序。
点列头：设为或取消重点组（最多 3 个，蓝/橙/青）；点行名：设为当前方面；点格子：两者都做。
C

细看

?每行一个组，行的顺序与 B 的列相同。横轴是当前方面（所有行共用）。每张图按分数放在横轴上，同一位置向上堆叠，堆得越高 = 越多图在这里（组多时会叠在一起，但高度仍表示数量）。
每行下方：竖线 = 中位数，色条 = 中间 50%；右侧离散度越小越集中。
在顶部共同轴上拖动：在所有组上同时选中这个分数区间，并画出贯穿所有行的竖带。在某一行里拖动：只选这一组的一段。点行名设为或取消重点组。

选中的图

?框选一批图后：选中图与其余图的平均图对比；这批图来自哪些组；与同一 prompt 下其余的图相比，在哪些方面偏向一端（单位：本 prompt 内的标准差；点击一行可设为当前方面）；按组分开的图像证据。
"记录为发现"会保存当前的 prompt、方面、重点组、选中的图和你的备注，可在下方"发现记录"中点击恢复，或导出。
没有选择时，这里显示当前方面上各组的集中程度排名。
方面分数来自 CLIP 的近似测量，需要对照图像核实。
