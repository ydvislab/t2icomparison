# 画面方面的测量

`aspects.py` 定义 15 个双极方面，每个是一对英文描述（左端 ↔ 右端），附中文名。`build.py` 对两个背景实验的全部基础图像（1056 张，其中 768 张进入比较系统）：
1. 用 CLIP ViT-L/14 提取图像特征（L2 归一化）；
2. 方面分数 = 与右端文字的余弦相似度 − 与左端文字的余弦相似度；
3. 生成缩略图（96²）、详情图（384²）和每组每 prompt 的像素平均图。

输出到 `$T2IC_DATA/proto2/`：`emb.npz`、`data.js`、`img/{t,f,avg}/`。（目录名沿用早期原型的名字，以免已有数据失效。）

```bash
~/va4ext/env/bin/python build.py
```

在 Mac（MPS）上约几分钟。2026-10-10 重新运行，输出与原有数据逐位相同。

**注意**：标准化（每个 prompt 内）和集中程度在 `system/` 里计算，这里只给原始分数。方面是否可信要看 `annotation/` 的人工核对结果；已知含混的方面：色调（混了新旧与配色）、构图（混了居中与对称）、画质（测的是"专业摆拍 vs 随手拍"的措辞）。
